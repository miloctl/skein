# Skein frontend

Next.js 16 + @assistant-ui/react + Tailwind. This is the web UI for the
Skein team platform — see the [root README](../README.md) for setup, the
Docker story, and everything else.

```bash
npm install && cp .env.local.example .env.local
npm run dev     # :3000 (backend expected on :8000)
npm run build   # verify compile before committing
```
