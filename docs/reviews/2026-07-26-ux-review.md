# Whole-app UX review — 2026-07-26

> **Status (2026-07-27): CLOSED — Q1-Q8, S1-S8, and L1-L7 all shipped across the 2026-07-26/27 batches (5-item nav, inline forms, manager toggle, capture affordances, key self-request, req: routing, agent status strip, digest hygiene).**

Trigger: "it still feels a bit overwhelming and not intuitive for users."
Method: three independent reviews (UX research / cognitive load, information
architecture, product jobs-to-be-done) over the full codebase, plus a live
first-run walkthrough in Chrome as a brand-new anonymous user on the LAN URL.
Proposals only — nothing here is implemented except the two crash-class fixes
noted at the bottom.

## The convergent diagnosis

All three reviews, independently, landed on the same three roots:

1. **Structural: 12 top-level pages for ~5 jobs.** Four pages claim to be
   "the overview" (My Day, Dashboard, Portfolio, Insights). Dashboard is an
   11-entity dump with no audience; the one daily ritual (standup) lives on
   it while My Day — the page that IS the daily driver — has no composer.
2. **Vocabulary: core nouns collide.** Nav "Notes" opens /ingest (paste
   meeting notes) while "Knowledge base" notes live on Dashboard and private
   notes live on People. "Review" means four things (inbox page, attention
   group, authority level, decision half-life). Three different "pulses".
   "Commitment line" vs "Commitments" vs the "Commit" attention group.
3. **No progressive disclosure.** Every dev sees the manager cockpit (exec
   readout, slip forecast, authority matrix editor, triage buttons, MTTR
   analytics) as peers of My Day. Half the perceived size of the app is
   workload most users will never touch.

## Target IA (synthesis of IA5/UX5/PM2)

```
My Day (/)        default for everyone; + standup composer; + attention badge
Chat              unchanged
Work              Portfolio renamed; tabs: Health (portfolio) · Browse
                  (dashboard's entity lists, per-engagement) · Insights
Inbox             Review renamed; keeps badge; tabs: Proposals · Requests
                  (intake triage) · Paste notes (ingest)
Team              tabs: Agents · 1:1s (People) · Charter · Roster (from Settings)
⚙ Settings, ⌘K    unchanged
```

Every demoted page keeps its URL; nothing is deleted, the nav drops 12 → 5.

### Live-walkthrough findings (mine, not in the agent lists)

| id | surface | problem |
|---|---|---|
| L1 | My Day "Since yesterday" | Raw activity log leaks internals: "delete chat thread 4df779fc-6b72-…" — UUIDs and plumbing verbs in a human digest. Filter/round-trip to human phrasing ("claude tidied 3 chats"), drop UUIDs. |
| L2 | My Day notices | Truncation mid-word without ellipsis: "0 tasks do", "0 blocke". Also zero-value stat strings ("0 days · 0 milestones · 0 tasks") read as noise — omit zero segments. |
| L3 | My Day notices | Near-duplicate notices stack ("claude ingested meeting notes: 1 proposal(s)…" twice). Coalesce by kind+actor within a day. |
| L4 | Insights findings | Six red "Scheduled job X has not succeeded" alarms — while the scheduler is deliberately off (STRANDS_SCHEDULER=0). Suppress job-staleness findings when the scheduler is disabled; one line "scheduler off" instead of six alarms. |
| L5 | Portfolio | "kept / missed" render as buttons on team commitments for everyone — action affordance on display data (and no confirm). Show state as a chip; the verdict buttons only behind the manage disclosure. |
| L6 | everywhere | Full ISO timestamps ("2026-07-26T03:21:07+00:00") in Mission Control and notices — humanize ("3h ago"). |
| L7 | /agents | Authority matrix is a raw text-input + two dropdowns + Set — no list of current grants, free-text agent name. Show the current matrix as rows with inline change controls. |

## Recommended sequencing

1. **Batch 1 (now):** Q1–Q8 + L1–L6 — copy, ordering, and honesty fixes.
   Nothing moves routes; ~a day of work; removes the sharpest confusion.
2. **Batch 2 (the structural release):** S1 (nav+merge) with S3 riding along,
   then S2 (prompt() → forms) — this is what changes "overwhelming" to
   "small". L7 fits here.
3. **Batch 3 (flow depth):** S4–S8 — daily-ask reduction, key bootstrap,
   capture affordances, request routing, agent status.

## Fixed during this review (crash-class, already pushed)

- `crypto.randomUUID` is secure-context-only → /chat hard-crashed for any
  browser without a stored last-chat id when served over plain http on a LAN
  IP (the production deployment shape). Fallback via getRandomValues.
- `navigator.clipboard` same restriction → every copy button silently dead
  on LAN http. Shared `lib/clipboard.ts` with hidden-textarea fallback.
